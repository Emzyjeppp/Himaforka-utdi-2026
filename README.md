# HIMAFORKA UTDI Web Platform

Repositori resmi untuk platform web Himpunan Mahasiswa Informatika (HIMAFORKA) Universitas Teknologi Digital Indonesia (UTDI) periode 2026/2027.

Situs web ini dirancang ulang menggunakan stack modern untuk memberikan pengalaman pengguna yang lebih cepat, bersih, dan informatif bagi anggota dan mitra eksternal HIMAFORKA.

## Fitur Utama
- **Landing Page Modern**: Desain bersih berbasis Tailwind CSS dengan dukungan tema gelap (Dark Mode) dan tipografi yang elegan.
- **Portal Informasi**: Menampilkan sejarah, visi misi, struktur divisi, dan pengurus harian HIMAFORKA.
- **Dashboard Anggota**: Akses khusus anggota untuk melihat rekap dan jadwal kegiatan (LPJ) himpunan.
- **Kinerja Optimal**: Dibangun di atas Next.js App Router (React) untuk performa dan SEO yang maksimal.

## Teknologi
- [Next.js](https://nextjs.org/) (App Router)
- [React](https://reactjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)

## Pengembangan Lokal

1. Clone repositori ini:
   ```bash
   git clone https://github.com/Emzyjeppp/Himaforka-utdi-2026.git
   ```
2. Instal dependensi:
   ```bash
   npm install
   ```
3. Jalankan server pengembangan lokal:
   ```bash
   npm run dev
   ```
4. Buka [http://localhost:3000](http://localhost:3000) di peramban Anda.
