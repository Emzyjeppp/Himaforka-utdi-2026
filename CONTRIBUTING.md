# Pedoman Kontribusi (Contributing)

Terima kasih atas ketertarikan Anda untuk berkontribusi di repositori HIMAFORKA UTDI!

## Cara Berkontribusi

1. **Laporkan Isu (Bug / Masalah)**
   Jika Anda menemukan *bug* atau tautan yang rusak, silakan buat *Issue* baru dengan detail langkah-langkah untuk mereplikasinya.

2. **Usulkan Fitur Baru**
   Punya ide bagus untuk pengembangan web himpunan? Buat *Issue* dan gunakan label `enhancement`. Kami sangat terbuka pada gagasan baru.

3. **Mengirimkan Pull Request (PR)**
   * Lakukan *fork* pada repositori ini.
   * Buat *branch* fitur Anda (`git checkout -b fitur/NamaFiturAnda`).
   * Lakukan perubahan dan *commit* (`git commit -m 'Menambahkan fitur XYZ'`). Pastikan kode Anda mengikuti format aturan desain kami (*devflow-rules* / Impeccable Design).
   * Dorong ke *branch* Anda (`git push origin fitur/NamaFiturAnda`).
   * Buka *Pull Request* baru.

## Aturan Gaya Kode (*Coding Guidelines*)
* Jangan gunakan emoji pada UI atau di dalam kode.
* Utamakan fungsionalitas dan pustaka bawaan (*lean*).
* Pastikan desain tidak terjebak pada tren "AI Boilerplate" (misal: menghindari struktur *bento grid* berlebih atau ornamen visual yang tidak ada fungsinya).
